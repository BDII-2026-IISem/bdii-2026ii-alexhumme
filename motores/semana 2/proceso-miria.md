# SEMANA 4: Proceso creacion BD en MYSQL, POSTGRES, MSSQL y ORACLE

## OBJETIVO:
Diseño e implementacion progresiva de una base de datos relacional portable denominada movilcare, cuya construccion inicial es en mysql dentro de docker, acceso remoto con DBeaver, validacion de entidades campos, claves y relaciones; posteriormente replica controlada del modelo en PostgreSQL, Microsoft SQL Server y Oracle
## SPEC + AC

| Codigo   | Descripcion | Aplicacion |
|:--------:|:--------    | :--------  |
| SPEC-01  | Construir una base de datos denominada movilcare | Base de datos parala platataforma de una tienda que comercializa equipos y accesorios que lleve trazabilidad de inventarios, recepciones, diagnosticos y clientes |
| SPEC-02  | Verificar diseño y persistencia | Comprobar la correcta construccion de la base de datos, funcionamiento y su estructura, asi como la permanencia de los datos |
| SPEC-03  | Backup y Script BD completa | Creacion de respaldo de la BD y script funcional |
